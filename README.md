# OVERSLAB

Website-Mockup: Rahmen mit erweiterter Illustration für PSA-gegradete Yu-Gi-Oh!-Overframe-Karten.

- `index.html` – komplette Seite (HTML/CSS/JS, keine Build-Tools)
- `img/cards/` – Overframe-Scans, ein Bild pro Motiv
- Neues Motiv: Bild nach `img/cards/<slug>.jpg`, eine Zeile im `CARDS`-Array in `index.html`

Lokal ansehen:

```bash
python3 -m http.server 8765
```

Bildquellen: Yugipedia (Kartenscans), eigene Fotos. Yu-Gi-Oh! und die Illustrationen sind Eigentum von Konami.
